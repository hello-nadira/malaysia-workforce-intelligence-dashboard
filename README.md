README — Malaysia Workforce Intelligence Dashboard

An executive-ready business intelligence dashboard that visualises
Malaysia's Monthly Principal Labour Force Statistics from the official
open-data portal (data.gov.my).

## Quick start

```bash
# 1. Clone and enter the project
git clone <repo-url>
cd dashboard_proj

# 2. (Optional) Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the dashboard
streamlit run dashboard.py

# 5. Run the tests
pytest tests/ -v
```

## Data source

- **Dataset:** Monthly Principal Labour Force Statistics
- **Provider:** Department of Statistics Malaysia (DOSM)
- **URL:** https://data.gov.my/data-catalogue/lfs_month
- **CSV:** https://storage.dosm.gov.my/labour/lfs_month.csv
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)

## Key columns in the CSV

| Column          | Unit              | Description                              |
|-----------------|-------------------|------------------------------------------|
| date            | YYYY-MM-DD        | Month (day is always 01)                 |
| lf              | thousands         | Labour force size                        |
| lf_employed     | thousands         | Employed persons                         |
| lf_unemployed   | thousands         | Unemployed persons                       |
| lf_outside      | thousands         | Persons outside the labour force         |
| p_rate          | percent           | Participation rate                       |
| ep_ratio        | percent           | Employment-to-population ratio           |
| u_rate          | percent           | Unemployment rate                        |

## Important caveat — 2025 population-reference change

Data prior to 2025 uses population benchmarks from the 2010 Census.
Data from 2025 onwards uses population benchmarks from the 2020 Census.
This creates a **methodological break** in the series. Comparisons
(month-on-month, year-on-year) that span January 2025 must be
interpreted with care — the observed shift may reflect the revised
population denominator, not an economic change.

## Architecture decisions

- **Separation of concerns:** All data logic lives in `src/` modules
  with zero Streamlit imports. Streamlit (`dashboard.py`) is a thin
  presentation layer.
- **Disk-based caching:** Data is cached as Parquet in `.dashboard_cache/`.
  If the live download fails, the app falls back to the last cached
  version and shows a visible warning.
- **Deterministic insights:** Executive insights are generated by
  rule-based logic — no LLMs or external AI APIs.
- **No hardcoded values:** All KPI values come from the live CSV at
  runtime. No production figures are ever embedded in code.
